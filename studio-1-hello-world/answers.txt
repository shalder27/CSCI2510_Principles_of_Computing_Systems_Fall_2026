10. When the third argument is much larger than the actual buffer, write() attempts to write that many bytes starting from the buffer's address. Since the buffer does not contain that many valid bytes, it reads beyond the buffer. This is undefined behavior and may print garbage or unrelated memory contents, or otherwise behave unpredictably.
11. I would use a C library function when I want portable, convenient code that can work across different operating systems, such as using fprintf() for formatted output. I would use an OS system call when I need lower-level control or direct access to operating-system functionality, such as using write() to write bytes directly to a file descriptor.

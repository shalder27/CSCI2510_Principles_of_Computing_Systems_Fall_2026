Exercise 6:
I created a custom signal handler to handle SIGINT.

void handle_sigint(int signum) {
    const char msg[] = "Parent is ignoring SIGINT!\n";
    write(STDOUT_FILENO, msg, sizeof(msg) - 1);
}

The handler is registered in main() using:

signal(SIGINT, handle_sigint);

Exercise 8:
Signal handling is useful when a child process terminates.
The operating system sends SIGCHLD to its parent process.
The parent can handle this signal and use waitpid() to
collect the child's exit status without continuously
checking whether the child has finished.

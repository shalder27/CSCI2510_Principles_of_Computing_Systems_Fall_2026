Parsing String Input

Exercise 1:
Program reads input using fgets() and prints it.

Example output:
Enter input: Hello World
Hello World

Exercise 2:
The first call to strtok() takes the input string
as its first argument. Subsequent calls use NULL
to continue parsing the same string.

Exercise 3:
Use a space (" ") as the delimiter for regular
text input.

Exercise 4:
Code:
char *token = strtok(buffer, " ");
printf("%s\n", token);

Example output:
Enter input: Hello World
Hello

Exercise 5:
Code:
char *token = strtok(buffer, " ");
while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, " ");
}

Example output:
Enter input: Hello World from C
Hello
World
from
C
